# Personal Portfolio Website

A clean, responsive, and modern personal portfolio website built with semantic HTML5 and CSS3.

## Project Description
This portfolio website showcases my background, technical skills, projects, and contact details. It is built from scratch without external frameworks to demonstrate fundamental web development skills.

## Features
- **Semantic HTML5:** Uses header, nav, main, section, article, and footer tags.
- **CSS Grid & Flexbox:** Fully responsive layout adapted for both mobile and desktop screens.
- **Interactive UI:** Includes custom hover effects on buttons and navigation links.
- **Contact Form:** Interactive structured web form with input validation.

## File Structure
- `index.html`: Contains all website sections and structure.
- `style.css`: Modern styling rules, color palette, and layout responsiveness.
- `images/`: Stores assets including profile picture and project thumbnails.
